# ManhwaUS

Aplikasi Android pribadi untuk membaca manhwa di [manhwaus.net](https://manhwaus.net/) tanpa browser.

## Unduh APK

Buka halaman **[Releases](../../releases/latest)**, unduh `ManhwaUS.apk`, lalu install di HP
(izinkan "Install unknown apps" kalau diminta). Setelah itu aplikasi memberi tahu sendiri kalau ada versi baru.

## Fitur

- Adblock bawaan dan DNS-over-HTTPS (tetap bisa dibuka walau diblokir operator)
- Tampilan seragam: header merah, kartu, teks Indonesia
- Bilah navigasi bawah: Beranda, Cari, Riwayat, Bookmark, Akun
- Cari: kategori (Semua, Tamat, RAW), genre, urutan (Terbaru, Populer, Rating, A–Z), Ranking
- Detail: rating, status, sinopsis, genre, tanda chapter yang sudah dibaca, tombol "Lanjut baca"
- Membaca: bilah atas/bawah, penanda halaman (12 / 24), lanjut otomatis ke chapter berikutnya,
  muat ulang gambar yang gagal, zoom dua jari
- Riwayat baca: chapter & halaman terakhir, lanjut dari posisi terakhir, tanda chapter baru
- Tab Akun: status login, Masuk/Daftar, Log Out, tema (Ikuti sistem / Terang / Gelap), cek update, bersihkan cache
